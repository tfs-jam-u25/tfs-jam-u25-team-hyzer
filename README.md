# tfs-jam-u25-team-hyzer

## What is Cult of the Reaper

Cult of the Reaper started as a submission to the TFS Summer 2025 Game Jam and continues to slowly grow as team members continue with the project in their spare time.  

In its current state it is a humble 2D pixel art platformer whose main character makes up for their cuteness with some sinister scythe work.  

Stay tuned for more about its future.
